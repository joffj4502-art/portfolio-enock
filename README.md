# Portfolio d'Enock — HTML & CSS

Un portfolio personnel et responsive réalisé uniquement en HTML et CSS, sans JavaScript ni framework.

## Fichiers du projet

- `index.html` : contenu et structure du site.
- `style.css` : mise en page, couleurs et adaptation aux ordinateurs, tablettes et téléphones.
- `README.md` : présentation du projet et instructions d'installation et de publication.
- `GITHUB_ETAPES.txt` : guide des étapes de publication sur GitHub.

## Tester le site sur un ordinateur

1. Télécharge et décompresse le dossier du projet.
2. Ouvre le fichier `index.html` dans ton navigateur.
3. Vérifie que les fichiers `index.html` et `style.css` se trouvent dans le même dossier.

## Technologies utilisées

- HTML5 pour structurer les pages.
- CSS3 pour la mise en page et le design responsive.
- Polices système pour assurer une bonne lisibilité sans dépendre de bibliothèques externes.

Le site peut être consulté localement sans connexion Internet, à condition que ses fichiers soient disponibles sur l'ordinateur.

## Publier le portfolio avec GitHub Pages

1. Connecte-toi à [GitHub](https://github.com/).
2. Ouvre le dépôt public `portfolio-enock`.
3. Envoie les fichiers `index.html`, `style.css`, `README.md` et `GITHUB_ETAPES.txt` avec **Add file → Upload files**, si nécessaire.
4. Clique sur **Commit changes** pour enregistrer les modifications.
5. Ouvre **Settings → Pages**.
6. Dans **Build and deployment**, sélectionne **Deploy from a branch**.
7. Choisis la branche `main` et le dossier `/(root)`.
8. Clique sur **Save** si tu as modifié les paramètres.
9. Attends la fin du déploiement et vérifie le résultat dans **Settings → Pages**.
